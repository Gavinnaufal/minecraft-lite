# Paket Dokumentasi — Mini Minecraft

Paket dokumen lengkap ala studio game untuk proyek **Mini Minecraft** (voxel sandbox web, Three.js + TypeScript), disiapkan untuk workflow vibe coding dengan **DeepSeek V4 Pro**.

## Isi paket

| File | Isi |
|---|---|
| `01_GDD.md` | Game Design Document — visi, mekanik, kontrol, scope MVP vs stretch |
| `02_PRD.md` | Product Requirements Document — requirement fungsional/non-fungsional, metrics, risiko |
| `03_ARSITEKTUR_FOLDER.md` | Struktur folder & file project, prinsip modularitas |
| `04_ROADMAP.md` | 130 checkpoint pengembangan, dibagi 16 fase |
| `05_PROMPT_DEEPSEEK.md` | Prompt siap pakai untuk DeepSeek V4 Pro, 1 prompt per checkpoint |
| `06_TASK_BOARD.md` | Task board/kanban untuk tracking progress harian |

## Cara mulai

1. Baca `01_GDD.md` dan `02_PRD.md` sekali untuk paham gambaran besar.
2. Setup project sesuai `03_ARSITEKTUR_FOLDER.md` bagian setup awal.
3. Buka `06_TASK_BOARD.md`, mulai dari CP1.
4. Untuk tiap CP, ambil prompt dari `05_PROMPT_DEEPSEEK.md`, jalankan di DeepSeek V4 Pro, uji hasilnya sesuai kriteria di `04_ROADMAP.md`, lalu commit & centang task board.
5. Ulangi berurutan sampai CP130 (atau berhenti di CP102 kalau cuma butuh MVP playable).

Selamat membangun dunia voxel-mu sendiri. 🧱
